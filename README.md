# 🛒 ShoppingList

A simple Android app to manage your shopping list.

## ✨ Features
- Add items to list
- Edit existing items
- Delete items
- Simple and clean UI

## 🛠️ Tech Stack
- Kotlin + Jetpack Compose
- MVVM Architecture

## 🚀 Getting Started
1. Clone the repo https://github.com/Harshal-Deshmukh/ShoppingList.git
2. Open in Android Studio
3. Run the app
